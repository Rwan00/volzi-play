# Volzi Play

An iOS video player with a midnight-navy and ice-teal interface. Paste an `m3u8`, `mp4`, or another supported link, then tap Play. A public sample stream is available on the home screen.

## Run

iOS only.

```bash
flutter pub get
flutter run
```

Open `ios/Runner.xcworkspace` in Xcode if you need to sign for a physical device.

## Pages

The side menu includes About, How to use, Supported formats, FAQ, Privacy, Terms, Copyright, Disclaimer, and Contact.
